Flipper Mermaid

Codex-guided. ADL-governed.

A multi-device control stack for authorized Flipper Zero automation. Codex plans the run, ADL validates the requested capability and execution context, the S3 Core coordinates transport, the CYD Deck provides approvals, Vision can verify state, and the C3 Sentinel keeps the hardware path fail-closed.

One orchestration plane, multiple trust boundaries

Mermaid keeps planning, authority, transport, approval, sensing, and hardware execution distinct. That makes the system easier to audit and lets Codex automate workflows without making the model itself the final hardware authority.

Codex

Builds structured run plans, resolves needed adapters and scripts, and interprets results.

ADL

Validates capabilities, arguments, authorization context, dependencies, and approval requirements.

S1r3n Core

Compiles approved intent into bounded device jobs and coordinates transport and telemetry.

Deck + Sentinel

Human approval and independent fail-closed hardware interlock remain outside the planning model.

Installer and device console

The Pages installer provides browser-side serial discovery and diagnostics. Firmware installation is only enabled when real build artifacts are published, so the interface does not claim a successful flash when no binary exists.
